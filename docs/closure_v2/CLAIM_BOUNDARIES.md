# Closure V2 Claim Boundaries

| Evidence | Maximum wording | Forbidden wording |
|---|---|---|
| V1 frozen | Closure V1 result at its published authority | retroactive V2 correction |
| V2 legacy holdout | retrospective complementary analysis | new confirmation, prospective validation |
| V2 fresh WQP locations | internal evaluation on WQP monitoring locations unused by V1 | external validation, unseen waterbodies |
| V2 forward temporal | post-lock temporal evaluation | geographic transfer |
| Compatible external source | external validation under the documented contract | universal generalization |
| Degradation | robustness under simulated missingness | field robustness guarantee |
| Planning | simulated decision-support comparison | causality, official recommendation, universal optimum |

P0/P1 are described as residual probabilistic GRUs. “Canonical GRU-D” is
forbidden unless masks and temporal decay are implemented and separately
validated. “Equivalent” is forbidden without a preregistered equivalence
margin and formal design. Missing estimates remain non-estimable, never zero.
