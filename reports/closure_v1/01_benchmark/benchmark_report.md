# Closure V1 E1 unified benchmark

All model slots were evaluated on the same locked intent/outcome keys. No model was fitted, recalibrated, replaced, or silently removed in E1.

- paired prediction rows: 673200
- paired intent keys: 13464
- metric rows: 3300
- comparison rows: 180
- unavailable model ids retained: P0, P1, A2
- observation-weighted and site-weighted estimands are reported separately.
- noninferiority margins (PR-AUC 0.02; Brier 0.01) are project conventions, not ecological standards.
